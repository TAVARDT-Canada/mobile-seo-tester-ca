# Mobile SEO and Responsive Design Validator

[![Mobile SEO Validator](https://img.shields.io/badge/TAVARDT-Mobile%20SEO-5b3cf5.svg)](https://tools.tavardt.com/ca/mobile-seo-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Auditing viewport configurations, touch target sizes, and mobile viewport ergonomics.

Developed and maintained by the web performance architecture group at **TAVARDT**.

***

## Mobile SEO Inspection Features

* **Viewport Directive Assessment**: Rigorous validation of responsive viewport parameters and accessibility scalers.
* **Layout Flow and Content Overflow**: Pinpointing elements with static dimensions that compromise mobile responsiveness.
* **Tactile Target Evaluation**: Auditing button and link tap zones against modern touch interface criteria.
* **Text Readability Standards**: Checking base font sizes to eliminate friction on smartphone screens.
* **Mobile Readiness Index**: Quantitative rating from 0 to 100 with clear remedial steps.

***

## Installation and Usage

Compatible with Python 3.8+ using standard modules.

```bash
git clone https://github.com/TAVARDT-Canada/mobile-seo-tester-ca.git
cd mobile-seo-tester-ca
python mobile_seo_tester.py https://enterprise.ca
```

Export structured JSON report:

```bash
python mobile_seo_tester.py https://enterprise.ca -json
```
